# Project Singularity Recipes

A collection of setup recipes for Project Singularity.

See the recipe schema in [schema/recipe.schema.md](schema/recipe.schema.md).

## How to add a recipe

1. Place the recipe file under `recipes`.
2. Add an entry to `index.yaml`.
3. Open a Pull Request.

The distribution repository is [Sp3arHead/Project-Singularity-Dist](https://github.com/Sp3arHead/Project-Singularity-Dist).
